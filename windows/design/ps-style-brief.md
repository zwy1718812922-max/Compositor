# PS 风格与高级功能设计确认稿

日期：2026-10-10。当前可运行版本：0.3.0。本文记录拟议功能，不表示已经实现。

用户要求：补齐 PSD、蒙版等高级功能，参考提供的 Photoshop Windows 中文界面统一 UI；先看效果图，再决定正式界面。

## 视觉约束

- 以用户提供的 PS 截图为主要参考：中性深灰、紧凑中文菜单、工具选项栏、文档标签、横纵标尺、左侧窄工具栏及右侧可折叠面板。
- 保留 Compositor 品牌；控件、图标、输入框、选中态和面板密度统一。取消原界面的大品牌栏和独立快捷操作栏布局。
- 工作画布占主体，颜色/画笔/属性/图层面板使用矩形区域和细分隔线；颜色以灰色为主，蓝色用于少量焦点与选中态。
- 右侧图层行需能同时显示图层缩略图、蒙版缩略图、链接状态、组展开和锁定状态。
- 三张方案图比较经典面板布局、蒙版属性布局及图层管理布局，保持相同的 PS 视觉语言。
- 效果图是设计草案；正式 UI 与后端在用户选定方案后实施。

## 高级功能实施顺序

1. RGB 8 bit PSD 分层导入和导出：像素图层、名称、位置、透明度、常用混合模式、显示/锁定、图层组和像素蒙版。导出同时生成有效合成预览与分辨率元数据，并进行独立文件读回和像素比较。
2. 非破坏性像素蒙版：白显黑隐、灰色部分透明；从选区创建、画笔/渐变编辑、缩略图切换编辑对象、启用/禁用、反相、应用/删除及撤销重做。保留原图像素。
3. 图层组和剪贴蒙版；图层面板提供创建、移动、折叠及明确的层级反馈。
4. 逐步补齐套索/椭圆选区、选区羽化，以及色阶/曲线等调整。每项按独立的实际行为测试交付。

PSD 不应在首轮宣称兼容 Photoshop 的所有特性。CMYK、16/32 bit、PSB、智能对象、复杂图层效果和文字引擎须检测实际支持程度。未实现的内容要给用户可理解的导入说明，不应静默丢失、扁平化后仍称“无损”。导出文字的可编辑性与视觉保真需要单独验证。

## 代码影响

当前 Windows 项目为 .ccomp v2，图层仅包含 raster/text，蒙版和图层组将改变保存结构，实施时升级 Windows 格式、保留 v1/v2 读取，并同步 windows/FORMAT.md 与 docs/project-format.md 中的 Windows 说明。macOS 原始 .comp 结构与 ProjectManifest.current 不需要因独立 Windows 格式改动而修改。

主要接口：src/editor.js 图层合成；src/app.js 工具与历史；project.cjs 保存校验；main.cjs 原生文件操作；新 PSD 模块以及对应像素/文件测试。

## 技术参考

- PSD 读写候选：[ag-psd 官方 README](https://github.com/Agamnentzar/ag-psd/blob/master/README.md)。其文档说明了 RGB 写出、位深和文字等限制，选型需要实际样本验证。
- 蒙版交互参考：[Adobe 蒙版编辑说明](https://helpx.adobe.com/photoshop/desktop/create-masks/layer-masks/edit-and-refine-layer-masks.html)。缩略图边框表示当前编辑对象，黑/白/灰画笔控制可见程度。
