# 更新记录

## 0.6.0 · 2026-10-10

- Shift 等比 / 默认自由二维变换，旋转、组、多选和链接蒙版保留完整矩阵；取消完整恢复。
- 关闭当前文档标签、Ctrl+W 和未保存保护，应用保留空工作区。
- 可编辑纯色、渐变、自定义图案和 16 种调整图层，实时预览、选区蒙版和单步撤销；PSD 导出原生填充与调整描述，图案像素化。
- 画笔/橡皮擦按当前大小和画布缩放显示笔尖轮廓。
- 枚举全部本地 Windows 字体及样式，搜索、收藏置顶和持久保存；文字属性提供字形、粗体、斜体、下划线、段落对齐。
- 所有数字参数支持左键拖动；Shift 精细、Alt 加速、Esc 取消，文档参数拖动合并撤销。
- 标尺单位、可拖动原点和参考线；锁定/隐藏/清除、吸附、PSD/.ccomp 持久化与尺寸变更跟随。
- 本地 OpenVINO + U²-Net 轻量/完整模型抠图，实际 NPU 开关、CPU 回退、预览、边缘调整、可编辑蒙版及撤销。
- AI 运行组件和模型按需安装并校验 SHA-256，不增加基础安装包体积；支持进度、停止和重试。
- .ccomp 升级 v5，兼容 v1–v4；原 macOS 格式不变。

## 0.5.0 · 2026-10-10

- 修复复杂 PSD 自动合为一层，默认保留图层、组、常用 FX 与简单水平文字；保留合成预览选项。
- 增加 8 个实际缩放手柄和旋转手柄，多选及组变换、链接蒙版、Esc 取消。
- T 工具支持点文字、段落框、画布内编辑、对齐、行距、字距和单步撤销。
- 增加 PS 风格 FX 对话框、10 类实际渲染效果、预览及本机样式预设。
- 移动物件支持边缘、中心及等间距吸附，紫色参考线、像素间距、Alt 暂停和取消恢复。
- 增加 WebView2 轻量发行版及立即显示的启动动画；PSD 解析移到后台工作进程。
- .ccomp 升级 v4，兼容历史 v1–v3；原 macOS 源码与 .comp 格式不变。


## 0.4.0 — 2026-10-10

- 按已选方案 1 统一 PS 风格灰色菜单、工具栏、标尺、色板、画笔与图层面板。
- RGB 8 位 sRGB 分层 PSD 打开与导出，保留组、蒙版、剪贴关系和合成预览；不支持的内容明示预览确认。
- 像素蒙版黑白绘画、选区填充、渐变、反相、浓度、羽化、启用停用、链接变换和应用。
- 图层多选分组、拖动入组、组隐藏锁定、组透明度、复制和取消分组；剪贴蒙版。
- 柔边/硬边圆画笔、硬度、移动工具自动选择和变换控件显示开关。
- .ccomp 格式升级至 v3，兼容 v1/v2，组和蒙版参与尺寸操作、历史记录与像素预算。
- 26 项文件与桌面测试通过；导出的 PSD 通过独立 psd-tools 解码与重新合成检查；提供分层 PSD 示例。

## 0.3.0 — 2026-10-10

- 矩形选区、全选与取消；绘画、擦除、形状、填充、渐变和调整支持选区限制。
- 裁剪工具、裁剪到选区、九种锚点的画布尺寸修改；保留画布外图层像素。
- 等比图像重采样和分辨率修改，中文文字保持可编辑。
- 七项图像调整的实时预览、重置、取消及单步撤销。
- 前景色填充、像素清除、双颜色线性渐变。
- 向下合并、合并可见图层及文字栅格化。
- Windows 剪贴板图片复制与粘贴。
- 修复尺寸操作撤销后画布显示未同步的问题；文字栅格化计算真实笔画边界，保留顶部笔画。
- 新增图像、选择菜单及快捷键，更新帮助；16 项自动测试通过。

## 0.2.0 — 2026-10-10

- 按参考图重建新建画布对话框：八种预设分类、14 个打印预设、单位换算、横纵方向、分辨率及背景设置。
- 自定义预设保存、删除、搜索和最近使用项。
- .ccomp v2 保存分辨率和 sRGB 设置，兼容旧 v1 文件；PNG/JPEG 导出写入实际分辨率。
