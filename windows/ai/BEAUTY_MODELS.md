# Full local beauty models

No age editing, face replacement, quantization, pruning or compact backbone is used.

- Skin retouching: [Alibaba ModelScope cv_unet_skin_retouching_torch](https://modelscope.cn/models/iic/cv_unet_skin_retouching_torch/summary), model snapshot `30f890aab89b787aae93c3f396dbf32714bd950e`. The model card declares Apache License 2.0. Original U-Net, blemish detector, gated inpainting network and skin segmentation weights are used. ABPN: Adaptive Blend Pyramid Network for Real-Time Local Retouching of Ultra High-Resolution Photo, Lei et al., CVPR 2022.
- Face detection: full RetinaFace ResNet50 checkpoint supplied by the skin snapshot. [RetinaFace model card](https://modelscope.cn/models/iic/cv_resnet50_face-detection_retinaface/summary) declares MIT. RetinaFace, Deng et al., CVPR 2020; architecture derived from [Pytorch_Retinaface](https://github.com/biubug6/Pytorch_Retinaface).
- Vendored network definitions: [ModelScope](https://github.com/modelscope/modelscope/tree/958c3f7da68b700cc671134e267c356a2444398b/modelscope/models/cv/skin_retouching), commit `958c3f7da68b700cc671134e267c356a2444398b`, Apache 2.0, copyright Alibaba and affiliates. Full license: `beauty_models/LICENSE`. Imports were made local; unused MobileNet code and torchvision dependency were removed. The ResNet50 backbone retains all 3/4/6/3 bottleneck stages and the checkpoint names; `load_state_dict(strict=True)` verifies every parameter.

Weights download directly from their publisher using pinned SHA256 values in `beauty-manifest.json`. No model weights are bundled in the main application. The converted graphs retain FP32 weights (`compress_to_fp16=False`), without INT8 or FP16 weight compression. OpenVINO runs the retouching, detection and inpainting graphs on CPU with an FP32 precision hint. ONNX Runtime CPU runs the original skin graph because OpenVINO does not support its `tf_crop_and_resize` operator. First preparation reuses the existing Python/OpenVINO/NumPy/Pillow runtime and installs only missing, checksum verified CPU conversion/runtime wheels. Torch is used for first conversion only.

Native face crops retain source resolution for blemish repair. The main network's native 512 input predicts a blend field interpolated over the original pixels, following ABPN's original composition rule; this is not a compact replacement model. Blemish detection uses the original 768 input, inpainting uses overlapping 512 windows with feathered aggregation. Skin masks exclude eye/brow, lip and nostril neighborhoods and feather the face border. These exclusions reduce mistakes but are not a guarantee for all poses; users can disable a face, reduce strength or restrict blemish repair to drawn rectangles.

Editable PNG blend/repair patches and per-face controls are embedded in `.ccomp`; reopening and changing controls does not require models. Model analysis uses the preserved source image. Recompute after source pixel edits; moving/scaling does not require recomputation. One face ROI is limited to 4M pixels and one beauty filter's decoded patches to 16M pixels. Active model patches are retained inputs in the shared soft budget, released on filter/document disposal; tile outputs remain evictable. JPEG/PSD exports bake the same beauty formulas; `.ccomp` retains editability.
