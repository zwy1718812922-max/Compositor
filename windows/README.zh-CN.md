# Compositor 中文 Windows 版

这是基于 [robbietilton/Compositor](https://github.com/robbietilton/Compositor) 制作的独立 Windows 核心功能移植，版本为 **0.7.1**。原版 SwiftUI / AppKit / Metal 程序保留在仓库中；Windows 轻量版使用系统 WebView2、WinForms 与 Canvas 2D，另保留 Electron 兼容版，在本机运行，不需要账号或联网编辑。

## 直接运行

- **轻量安装版（推荐）**：运行 `dist/Compositor-ZH-0.7.1-x64-Lite-Setup.exe`，中文向导安装到当前用户程序目录。
- **轻量免安装版**：完整解压 `dist/Compositor-ZH-0.7.1-x64-Lite.zip`，双击 `lite-unpacked/Compositor 中文版.exe`。请保留同目录的 DLL、src、assets、ai 和 native 文件夹。
- **本地直接启动**：双击仓库根目录 `启动中文版.cmd`，优先运行轻量版。
- **Electron 兼容版**：运行 `dist/win-unpacked/Compositor 中文版.exe`；移动时保留整个文件夹。

轻量安装包约 0.70 MB，ZIP 约 0.83 MB，安装后应用文件约 2.22 MB（十进制 MB，不包含系统运行时及用户数据）。复用本机 WebView2 和 .NET Framework 4.8+，不打包完整浏览器；Windows 11 通常已具备这些运行时，缺失时程序会提供安装提示。参考 [Microsoft WebView2 分发说明](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution)。启动会立即显示动画；本机 0.7.1 安装版 WebView2 就绪测试约 0.63 秒，旧 0.4.0 自解压免安装 EXE 为 13.11 秒。其他电脑时间会不同。

目标系统为 Windows 11 x64。安装包暂未使用商业代码签名证书签名；Windows 可能显示未知发布者提示。

可通过“打开项目”载入 `examples/中文示例.ccomp`，体验包含可编辑中文文字、图层组和像素蒙版的示例。另有 examples/中文示例.psd 可用于分层交换。界面预览见 `preview.png`。

## 0.7.1 性能修复

- 直接读取 PSD 的图层像素及文字、组、蒙版、FX 元数据，去掉“逐层压缩 PNG，再解码”的导入中间步骤；轻量宿主使用一次性本地二进制通道，避免大文件转 Base64 JSON。
- 大画布按显示比例和视口绘制；缓存未变化图层的 FX、蒙版与填充，纯色直接绘制。100% 显示按视口保留原始像素精度。保存、导出和复制合成画面使用完整文档尺寸，原始图层像素不缩小。
- 撤销在内存里共享未变化的独立像素快照，避免拖动开始时编码整份 PNG；对未羽化蒙版的自动选择只取命中点像素，避免为一次点击计算整张蒙版。修复替换蒙版后旧缓存仍被使用的问题。
- 本机 113.7 MB、3508 × 4961 的 36 节点展板：PSD 读取约 8.02 秒降至 1.31 秒，完整打开约 1.57 秒；真实拖动单次处理约 7–25 ms，选色约 5–7 ms。测试方法与限制见 [验证记录](VALIDATION.md)。

PSD 仍需解码后进入编辑器，未使用 Photoshop 引擎；已有智能对象、复杂文字、颜色模式等兼容范围仍适用。工作项目保存为 `.ccomp`，分层 PSD 使用导出；没有无损改写任意 PSD 未知记录的能力。项目格式保持 v6，可继续打开旧文件。

## 0.7.0 新增操作

- 启动进入主页：新建/打开文件、最近项目缩略图、时间和路径；点击最近项目重新打开。移除记录保留原文件。主页按钮可以在编辑时返回主页。
- 多个文件同时保留在文档标签中；每个文件具有独立图层、保存路径、撤销记录、选区和视图。点击标签切换，× / Ctrl+W 关闭当前文件；退出时逐个保护未保存文档。当前版本使用标签工作区，没有独立浮动文档窗口。
- 颜色选择在本机记忆；新建填充采用上次选择的颜色。填充/调整及模糊的实时预览不添加暗色背景遮罩。画布外围点击收起变换控件，重新选择图层恢复。
- 移动工具按住 Alt 拖动，复制选中的图层或整个组，蒙版独立复制；Esc 取消，撤销一次恢复原状。Ctrl 拖动临时暂停吸附。
- 长按或右键左侧 W 工具，切换对象选择、快速选择、魔棒。对象选择框内运行本地 U²-Net；快速选择按笔刷采样相近颜色，魔棒支持容差/连续/全部图层。Shift 添加、Alt 减去，也可在选项栏交叉选区；“应用为蒙版”保留源图。快速选择是颜色区域算法，不能保证与 Photoshop 智能选择相同。
- 选择主体支持输出可修整的选区或图层蒙版。对象框选自动推理，结果支持羽化、边缘偏移及与现有蒙版相交。NPU 开关保持可用，界面显示实际执行设备。
- 滤镜提供高斯、方框、动感、径向、表面、平均六种模糊；预览、停止/取消、参数拖动及单步撤销。动感可调角度，径向可调方法和中心，表面可调阈值。请选择未锁定的像素图层，文字/填充先栅格化。算法近似 Photoshop，未实现镜头模糊和模糊画廊。
- 新建选择 RGB 或 CMYK，可加载自定义 CMYK ICC。默认使用本机 Windows SWOP 配置文件，Little CMS 处理预览及真实四通道分层 PSD 导出/导入。PNG/JPEG 仍为 RGB。**内部使用 RGB 中间图像合成，往返转换存在色差，不能完整保留原始四色分色、黑版或专色**。格式说明见 [v6](../docs/windows-format-v6.md)。

## 0.6.0 新增操作

- 当前文档标签的 **×**、文件菜单或 **Ctrl+W** 关闭当前项目，保留应用窗口；未保存时可保存、不保存或取消。
- 图层面板底部 **◐** 创建可编辑纯色、渐变、图案与 16 种调整图层；双击缩略图可再次修改。创建时存在矩形选区会生成对应蒙版。自定义图案可以导入图片。
- 数字输入框或参数名称上按住鼠标左键左右拖动，实时调节；Shift 精细、Alt 加速，Esc 取消，一次拖动形成一步撤销。仍可单击输入数字。
- 文字属性面板读取 Windows 系统与用户安装字体的字形样式；搜索字体、点击 ★ 收藏，收藏字体排在前面，并保存在本机。
- **Ctrl+R** 显示/隐藏标尺，右键切换像素、英寸、厘米、毫米、点。从横/纵标尺拖出参考线，拖动移动、拖出工作区或双击删除；视图菜单可以锁定、隐藏或清除。拖动标尺交点设置原点，双击复位。参考线支持吸附，保存到 .ccomp 与 PSD，不出现在 PNG/JPEG 中。
- 选择像素图片图层，使用“选择 → 选择主体 / 移除背景”或蒙版面板按钮。首次点击“安装本地 AI 组件”，下载约 101 MB；之后选择 U²-Net 轻量版或完整版，并启用/关闭 NPU。结果可预览、羽化、收缩/扩展边缘，应用为可编辑蒙版，原始像素保留。关闭 NPU 强制 CPU；NPU 缺失或模型不支持时说明原因并回退 CPU。所有推理均在本机。

AI 组件和权重按需下载，**不包含在 轻量基础安装包内**，缓存位于 `%LOCALAPPDATA%\CompositorZH\AI`。U²-Net 轻量权重 4.6 MB、完整权重 176 MB。运行时与权重使用固定版本及 SHA-256 校验；可停止安装或计算，离线时可使用已缓存组件。Windows 11 支持的 Intel NPU 需要对应驱动；其他厂商 NPU 尚未接入。详见 [AI 组件说明](AI.zh-CN.md)。

## 图层样式与智能参考线

点击图层面板底部 **fx** 或已有的 fx 标记，编辑斜面和浮雕（含等高线、纹理）、描边、内阴影、内发光、光泽、颜色叠加、渐变叠加、图案叠加、外发光及投影。预览勾选控制实时显示；取消恢复原设置，确定形成一步撤销。图案目前为程序生成的方格、条纹和圆点。常用样式导出为原生 PSD FX；程序图案及特殊浮雕在导出中烘焙到单层像素，.ccomp 保留可编辑参数。包含这些特殊效果的组需先合并再导出 PSD。复杂多重 FX、外部图案、复杂渐变和 PS 的部分高级混合选项有近似或未重现内容，导入报告会说明。

移动工具顶部默认启用“对齐吸附”。拖动时以物件可见像素的边界、中心以及画布作为参考；容差为屏幕 6 像素，随缩放换算。紫色线和数字显示实际对齐与间距，松开后消失，不会写进导出图片。Ctrl 暂停吸附，Alt 拖动复制，Esc 恢复整次拖动；多选及组作为整体移动，链接蒙版一起跟随。参考界面见 fx-preview.png 与 native-snap-preview.png。

## 新增编辑操作

按 **M** 拖出矩形选区，之后的绘画、填充、清除和图像调整会限制在这个范围内。**Ctrl+A** 全选、**Ctrl+D** 取消。Delete 在有选区时清除当前像素图层的选区内容，没有选区时删除图层；也可使用“编辑 → 清除像素”。选区暂不写入项目文件。

按 **C** 拖出裁剪范围，再按 Enter 或选择“图像 → 裁剪到选区”；Esc 取消。裁剪和“画布大小”保留画布外的原始图层像素，扩展画布后可以重新看见这些内容。修改画布不会降低图层内存占用。新增画布区域透明，使用新图层和填充可以添加背景。

按 **G** 拖动画线性渐变，在顶部设置起点、终点颜色和不透明度；渐变是独立像素图层。通过“图像 → 图像调整”可实时预览七项调整，取消不会改变原图或保存状态，应用后可一次撤销。调整在当前像素图层的原始像素空间进行，模糊半径随图层缩放改变；文字需要先栅格化。

“图像大小”保持比例重采样所有像素图层，并按比例调整文字和图层位置；文字仍可编辑。单独修改分辨率不会重采样像素。“画布大小”可自由输入宽高并选择锚点，改变边界而不缩放内容。

“向下合并”要求上下图层可见、解锁，并使用正常混合模式；其他混合模式可使用“合并可见图层”保留当前合成效果。合并仅保留画布范围内的内容；隐藏图层在合并可见图层时保留。文字栅格化后变为像素图层，撤销可恢复文字。

通过编辑菜单或 **Ctrl+Shift+C / Ctrl+Shift+V** 复制可见画面、粘贴 Windows 剪贴板图片。复制范围为矩形选区或整个画布；粘贴保持透明度，作为新图层居中，大图按导入规则等比缩小。Ctrl+C / Ctrl+V 继续用于文字编辑。

## PSD、蒙版与图层组

用 **Ctrl+O** 打开 `.psd`；用 **Ctrl+Shift+E** 在导出窗口选择“PSD”。单样式 PSD 文字（含可逆二维变换）作为可编辑文字导入，保留原始像素缓存直到首次修改字体或内容；复杂文字独立栅格化。导出简单文字和常用 FX 时同时保存原生 PSD 描述与像素缓存，几何变换保留在文字矩阵中。字体缺失或修改排版会使用本机字体，外观可能变化。PSD 不会覆盖当前 `.ccomp` 保存路径，导入后首次保存会另建项目。

选中图层后，点击图层面板底部的蒙版按钮。点击黑白缩略图进入蒙版编辑，点击图像缩略图返回图像编辑。黑色隐藏，白色显示，灰色半透明；蒙版上的橡皮擦恢复白色。**X** 交换前景色和背景色，**D** 恢复黑白。蒙版面板提供浓度、羽化、反相、停用、链接、应用和删除；Shift 单击蒙版缩略图可停用/启用。链接时移动、缩放、旋转图像会同步变换蒙版，取消链接后可单独移动蒙版。PSD 交换保留蒙版位置、像素、浓度、羽化和启用状态；编辑时的链接选择以 `.ccomp` 为准，PSD 导入默认链接。

**Ctrl+G** 将当前图层或 Ctrl 多选的相邻同级图层编组；**Ctrl+Shift+G** 取消分组。拖动图层到文件夹行可移入组，拖到同级普通行可改变顺序。组最多嵌套 10 层；父组的隐藏和锁定会影响子层。穿透组与正常隔离组均可设置透明度和像素蒙版。取消分组要求组可见、100% 不透明度及填充、穿透且无组蒙版或组样式，以保持原有画面。

**Ctrl+Alt+G** 创建/释放剪贴蒙版，基础层需位于同组下方。参与剪贴的组需要使用正常混合模式。删除基础层后，失去基础层的剪贴图层会自动释放剪贴关系。

复杂内容显示转换报告，默认“保留图层打开”，不会自动将整个文件合为一层。智能对象使用各自的独立像素缓存；调整层、矢量蒙版及高级混合不能完整编辑，按报告提示近似处理或保留占位层。另有“仅打开合成预览”供主动选择，对照原始合成画面；取消保留当前项目。16/32 位、PSB、非方形像素和 RGB 文档的非 sRGB 配置文件会提示先转换，避免直接按错误模式读取。本版不提供这些高级内容的完整编辑能力。

## 当前范围

本版本并非原版全部功能的等价移植。**尚不支持原版 `.comp`、PSB、RAW/HEIC/TIFF、复杂 PSD 文字、可编辑矢量蒙版、可编辑智能对象、自由形状选区、自由曲线点编辑、Camera Raw、压感、多文档标签页、自动更新和崩溃恢复。** 调整图层提供常用参数，算法近似 PS，不能保证与 Photoshop 色彩引擎完全一致。不应将 `.ccomp` 改名为 `.comp`。

画布每边限制 16384 像素，画布总像素不超过 64 × 1024 × 1024；最多 100 个图层，图层与蒙版合计也不超过 64 × 1024 × 1024；项目文件不超过 128 MB。分辨率为 1–9600 ppi。历史记录最多 25 步，并受内存预算限制。文字依赖本机字体，缺失字体时使用系统回退，跨电脑外观可能变化。

新版项目格式为 .ccomp v6，保存 CMYK ICC 模式、独立横纵缩放、剪切、可编辑填充/调整、字体样式及标尺参考线；可打开旧 v1–v5 文件，v1 默认按 72 ppi。v6 文件需要 0.7.0 或更新版本，格式说明见 [v6 格式](../docs/windows-format-v6.md)。旧 v4 的文字缓存及 FX 仍可读取。

## 从源码启动和打包

需要 Node.js 24 或更新版本、npm，以及 Windows x64：

```powershell
cd E:\Compositor\windows
npm ci
npm start
```

如本机 npm 禁止依赖安装脚本，导致缺少 Electron 运行库：

```powershell
node node_modules/electron/install.js
```

若无法连接 Electron 官方下载地址，可在当前 PowerShell 会话中设置下载镜像后重试（镜像属于第三方）：

```powershell
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"
node node_modules/electron/install.js
```

```powershell
npm test       # 项目校验、中文路径读写和真实 Electron 端到端测试
npm run pack  # Electron 解压版
npm run dist  # Electron 免安装 EXE 和中文 NSIS 安装包
npm run build:lite  # 编译 WebView2 轻量版
npm run dist:lite   # 轻量 ZIP 和中文安装包
npm run test:lite   # 真实轻量版功能检查
```

轻量编译使用系统 .NET Framework C# 编译器及 Microsoft.Web.WebView2 1.0.3179.45 SDK。默认从用户 NuGet 缓存读取；可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-native.ps1 -WebView2Package "SDK 解压目录"` 指定 SDK。可从 NuGet 的 Microsoft.Web.WebView2 对应版本取得 SDK；NSIS 打包默认使用 electron-builder 缓存的 makensis.exe，也可通过 package-native.ps1 的 -NsisCompiler 参数指定。

`npm test` 覆盖 20 项 Node 校验与 40 项真实 Electron 编辑器检查。`npm run test:lite` 验证真实 WebView2 程序；设置 COMPOSITOR_VERIFY_PSD 可验证指定实际 PSD。安装/卸载与剪贴板附加检查见 scripts/verify-native-package.ps1，会保留、恢复原剪贴板，并验证卸载不删除其他用户文件。

测试会短暂启动应用窗口，验证真实绘图像素、擦除、撤销重做、图层显示锁定、中文文字、重命名、图片导入、变换、保存重开一致性及 PNG/JPEG 文件写出。

## 代码位置

- `main.cjs`：Windows 窗口、中文菜单、原生文件对话框、保存与导出。
- `preload.cjs`：隔离的桌面接口；渲染页面无法直接访问文件系统。
- `project.cjs`：项目格式校验、读写和原子替换。
- `src/editor.js`：图层模型、合成、文字绘制、项目序列化。
- `src/app.js`：编辑交互、历史记录、工具及属性面板。
- `src/index.html` / `src/styles.css`：中文界面及布局。
- src/new-document.js / src/new-document.css：新建窗口、预设及物理尺寸换算。
- src/operations.js：选区裁切、尺寸重采样、文字栅格化和像素图像调整。
- image-metadata.cjs：PNG/JPEG 分辨率元数据。
- psd.cjs / src/psd-export.js：PSD 解码、校验和分层导出准备。
- src/advanced.js / src/layer-tree.js：蒙版、剪贴关系和图层树操作。
- src/ui-shell.js：菜单、色板、画笔预设和标尺。
