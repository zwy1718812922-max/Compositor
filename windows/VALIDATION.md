| --- | --- | --- | --- |
| core.psd | 4 / 1 | 0 | 0 |

## 复现

```powershell
cd E:\Compositor\windows
npm test
$env:COMPOSITOR_EXECUTABLE = "$PWD\dist\win-unpacked\Compositor 中文版.exe"
npm test
Remove-Item Env:COMPOSITOR_EXECUTABLE
node scripts/portable-smoke.cjs
```

免安装 EXE 会通过 NSIS 启动解压后的进程，不直接使用 Playwright 的 Electron 启动器；专用脚本连接其本地调试端口验证运行。

安装向导已成功构建，但未在本机执行安装/卸载，以免添加系统安装记录与桌面快捷方式。未测试 ARM64、不同 DPI、多屏、触控笔及其他电脑的字体环境。程序未签名；开发打包依赖的 npm audit 有中等风险提示，发布程序无生产 npm 依赖，`npm audit --omit=dev` 为 0。
