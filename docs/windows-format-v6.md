# Windows project format v6

Windows 0.7.0 writes `.ccomp` v6 and reads v1–v5. The macOS `.comp` schema and `ProjectManifest.current` remain unchanged. All v5 layer, mask, affine, guide and text fields remain valid.

The document adds required `colorMode`, either `RGB` or `CMYK`. `colorSpace` remains `sRGB` because editable image assets and composition use 8-bit RGB proxies. A CMYK document also requires `colorProfile: {name, data}`: a description up to 200 characters and base64-encoded CMYK ICC bytes. The profile must contain the `acsp` signature, `CMYK` input space, and be 128 bytes–4 MiB. The exact profile is embedded so that moving the project does not depend on the original profile path. RGB documents normally omit this field. Older versions cannot declare these new fields.

Little CMS applies relative colorimetric conversion with black-point compensation for a document's displayed CMYK proof and PSD output. Windows RSWOP.icm is the default profile; the user can select another valid CMYK ICC profile. No proprietary ICC profile is redistributed in the app. PNG/JPEG exports are RGB; layered CMYK PSD exports contain four ink planes, transparency, masks, groups and an embedded ICC resource. PSD import accepts 8-bit RGB/sRGB or CMYK with an embedded profile (falling back to Windows SWOP). This is not a native CMYK ink-channel editing engine: RGB proxy composition, adjustment/blend algorithms and 8-bit round-trips can change color and cannot preserve original ink separation or black generation exactly. It does not support spot colors, 16/32-bit PSD or PSB.

Selections, open document tabs, per-document history and viewport positions are session state. Irregular selections are canvas-space alpha bitmaps used by painting, fills, masks, filters and merged-copy clipping. They are not embedded in projects. Recent file paths/thumbnails and last chosen colors are user preferences in local storage. AI produces ordinary masks or session selections; its runtime, weights and device caches remain outside the project and app package.

Limits are unchanged: 100 layers and 64 million combined layer/mask pixels per document, 16,384 per side and 128 MiB project files. Six blur filters edit raster pixels and preserve alpha using premultiplied computation; previews are cancellable and application produces one undo entry. The Gaussian, radial and surface algorithms approximate Photoshop, rather than matching Adobe's proprietary algorithms.
